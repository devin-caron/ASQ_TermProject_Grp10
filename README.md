C# WPF multi-program system that simulates a live flight data management system
Implemented TCP/IP server for communication between the aircraft transmission program and the flight data management program
Created SQL database to store, format and retrieve the live flight coordinates from aircraft transmission system

1. Run Ground Station program
2. Run Aircraft Transmission System
3. Download Telemetry Data with option 1
4. Transmit Data to Ground Station with option 2
5. Ground station will receive live data until turned off then you may search/sort data or print to ASCII file
